# Piki Optimizer

**Ottimizzatore per PC Windows**: gaming a bassa latenza, ping basso e After Effects.
Rileva i componenti da solo, fa un check-up della salute del PC e applica solo ottimizzazioni sicure e **annullabili con un clic**.

## Download

- **Installazione rapida** (PowerShell):
  ```powershell
  irm https://raw.githubusercontent.com/piki04/piki-optimizer/main/install.ps1 | iex
  ```
- Oppure scarica lo zip, estrai tutto e fai doppio clic su **`Installa Piki Optimizer.cmd`**: crea l'icona nel menu Start e sul desktop e si disinstalla da Impostazioni > App.

Gli aggiornamenti arrivano da soli: l'app scarica **solo i file cambiati**.

## Cosa fa

| Sezione | Cosa fa |
|---|---|
| Il mio PC | Punteggio di salute e prestazioni, componenti, monitor CPU/RAM live, ottimizzazione in un clic |
| Check-up | Dischi (SMART/usura), schermate blu, errori hardware WHEA, driver, Windows, antivirus, temperature, RAM (XMP, single channel), Hz del monitor, rete |
| Ottimizza | Profili Gioco / Competitivo / Video e After Effects / Uso quotidiano / Portatile, con consigli basati sui tuoi componenti |
| Processi | Riduzione di servizi e processi in 3 livelli, app all'avvio, processi aperti. Ogni voce dice cosa smetterebbe di funzionare; quello che usi (stampante, Bluetooth, Xbox, Windows Hello…) viene protetto in automatico |
| Rete e Ping | Test ping/jitter/perdita pacchetti, test sotto carico (bufferbloat), DNS più veloce, ottimizzazioni TCP e scheda di rete |
| After Effects | Modalità Render, impostazioni consigliate calcolate per il tuo PC, priorità CPU, GPU dedicata, cache sul disco più veloce |
| Pulizia | File temporanei, cache aggiornamenti, dump, cache Adobe/browser/shader |
| Ripristino | Ogni modifica salvata e annullabile, punto di ripristino di Windows |
