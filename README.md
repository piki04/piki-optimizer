# Piki Optimizer 2.0

**Ottimizzatore gratuito per PC Windows**: misura il PC con numeri veri, lo velocizza solo con modifiche sicure e **annullabili con un clic**, e mostra prima cosa cambierebbe.

## Download

- Scarica `PikiOptimizer-2.0.0.zip`, controlla il codice SHA-256 pubblicato accanto, estrai **tutto** e fai doppio clic su **`Installa Piki Optimizer.cmd`**. Crea l'icona nel menu Start e sul desktop e si disinstalla da Impostazioni > App.
- Gli aggiornamenti arrivano da soli: l'app scarica **solo i file cambiati** e li verifica uno per uno.

## Cosa fa

| Sezione | Cosa fa |
|---|---|
| Il mio PC | Avvio di Windows, RAM usata, app all'avvio, spazio libero; un tasto "Velocizza il PC" |
| Misura | Prima e dopo con numeri veri (avvio, RAM e CPU a riposo, disco, ping), report da condividere |
| Velocizza | Profili PC lento / Piki / Gioco / Competitivo / Video / Uso quotidiano / Portatile, anteprima di ogni modifica, sessione Gioco temporanea |
| Avvio e app | Impatto di ogni app all'avvio (come Gestione attività), servizi in 3 livelli, processi aperti |
| Pulizia | File inutili, pulizia programmata settimanale o mensile (solo voci sicure) |
| Rete | Ping, jitter, test sotto carico, DNS più veloce |
| After Effects | Impostazioni consigliate per il tuo PC, sessione Render che si annulla da sola |
| Check-up | Dischi, schermate blu, driver, BIOS, sicurezza, temperature, memoria |
| Ripristino | Ogni modifica salvata e annullabile, punto di ripristino di Windows |

## Cosa NON tocca mai

Antivirus, firewall, Controllo account utente, SmartScreen, Windows Update e gli aggiornamenti di browser e app, i tuoi file. Se l'app non si apre, `Ripristina Piki.cmd` rimette tutto com'era.
